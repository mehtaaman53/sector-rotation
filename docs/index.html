Rotation chart (RRG)
Sectors ghadi ki ulti disha mein ghoomte hain: 🔵 Improving → 🟢 Leading → 🟡 Weakening → 🔴 Lagging. Line = pichhle 8 hafte ka safar, bada dot = abhi.
Sab sectors
RS > 100 = Nifty se strong · Mom > 100 = taqat badh rahi hai · Breadth = sector ke kitne % stocks 50 DMA ke upar · Top stocks = RS ke hisaab se sabse strong (✓ = 50 DMA ke upar)
